ROBERTO'S HOSE ROUTE - primera versión

1. Sube index.html, manifest.webmanifest y sw.js a un repositorio GitHub.
2. Activa GitHub Pages (Settings > Pages > Deploy from branch > main / root).
3. Abre la URL de GitHub Pages en Safari del iPhone.
4. Share > Add to Home Screen.

USO
- Mi ubicación: centra el mapa usando GPS.
- PIG: toca el punto donde está el pig/riser.
- Destino: toca hasta dónde necesitas llevar la manguera.
- Detectar obstáculos: obtiene edificios, agua y áreas forestales existentes en OpenStreetMap.
- Calcular ruta: traza una ruta evitando esos polígonos y estima los pies de manguera.

IMPORTANTE
Esta versión no puede reconocer automáticamente árboles/zanjas/cultivos directamente de fotografía satelital. Detecta obstáculos que ya estén cartografiados en OpenStreetMap. La siguiente versión puede incorporar imagen satelital y visión computacional con un proveedor de mapas/API apropiado.
